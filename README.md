# Cochrane Library Frontend

A modern React web application for browsing and searching systematic reviews from the Cochrane Library, the world's most trusted source of evidence-based healthcare research.

## 🔗 Live Demo

**[View Live Application](https://jitu0110.github.io/reactjs_cochrane/)**

## 📖 About

The Cochrane Library is a collection of databases that contain high-quality, independent evidence to inform healthcare decision-making. This frontend application provides an intuitive interface to explore thousands of systematic reviews, making evidence-based medical research accessible to healthcare professionals, researchers, and the public.

## ✨ Key Features

- **🔍 Smart Search**: Search through systematic reviews by topic with intelligent auto-suggestions
- **📱 Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **♾️ Infinite Scrolling**: Seamlessly load more reviews as you browse
- **🎯 Topic-based Filtering**: Explore reviews categorized by medical specialties and topics
- **📊 Professional Layout**: Clean, easy-to-read presentation of research data
- **⚡ Fast Performance**: Built with React 18 for optimal user experience
- **🔗 Direct Access**: Click any review title to access the full article on Cochrane Library

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (comes with Node.js)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Jitu0110/reactjs_cochrane.git
   cd reactjs_cochrane
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000/reactjs_cochrane` to view the application.

### Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.

## 🎯 How to Use

1. **Browse Reviews**: Scroll through the list of systematic reviews displayed on the homepage
2. **Search by Topic**: Use the search bar to find reviews on specific medical topics
3. **Auto-suggestions**: Start typing in the search box to see topic suggestions
4. **Filter Results**: Click on suggested topics to filter reviews
5. **Read Full Reviews**: Click on any review title to access the complete article on the Cochrane Library website
6. **Load More**: Scroll down to automatically load additional reviews

## 📊 Data Source

The application displays systematic reviews from the Cochrane Library, covering various medical specialties including:

- Allergy & Intolerance
- Blood Disorders
- Cancer
- Child Health
- Complementary & Alternative Medicine
- Consumer & Communication Strategies
- Dentistry & Oral Health
- And many more...

Each review entry includes:
- Review title and link to full article
- Author information
- Publication date
- Medical topic/specialty
- Direct link to the original Cochrane Library publication
